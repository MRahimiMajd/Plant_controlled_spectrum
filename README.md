# Plant_controlled_spectrum
The Python functions, supporting the analyses of the manuscript: The controlled spectrum of plant form and function (Rahimi-Majd et al.).

Please note that the Data folder contains the files “Above_traits.txt” and “Root_traits.txt” at the paths expected by the code; however, these files are intentionally left empty to acknowledge the original data repository (by Carmona et al., 2021). To run the functions, users must replace these files with the corresponding data downloaded from the Figshare repository:
https://doi.org/10.6084/m9.figshare.13140146

The functions in the file “partial_r_functions.py” reproduce the partial correlation statistics, while the functions in “pca_functions.py” perform and visualize the principal component analysis (PCA) plots presented in the study.

The analyses were tested using the following versions of Python and associated libraries: Python (version 3.12.12), numpy (version 2.2.6), pandas (version 2.3.3), scipy (version 1.16.3), pingouin (version 0.5.5), matplotlib (version 3.10.8), sklearn (version 1.8.0), adjustText (version 1.3.0).
